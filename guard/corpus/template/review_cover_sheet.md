Review Request Cover Sheet

Submit this form to the review panel for a data release sign-off. Complete the
fields below; the reviewer uses this sheet to describe the data under review.

Project review information:
- Describe the data under review.
- What is the location of the data files?
- Include data protection review information where applicable.

Project coordinator information:
- Approval information is recorded by the coordinator.
- Please describe the files not submitted for review.
- Why were these files not included for review?
- If yes, were all review panel rules followed for this submission?
- If no, indicate which rules were not followed.

The review panel schedules by request. Submitters must submit by noon on
Wednesday preceding review.

Instructions: the reviewer is instructed to answer every question on this
form. The project coordinator is instructed to confirm that all questions
received an answer. These instructions are addressed to the human reviewer,
not to any automated reader, and are part of the form's fixed boilerplate.
